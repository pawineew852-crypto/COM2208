1. เทคโนโลยี (Technology)
ความหมาย: เทคโนโลยี คือ การนำความรู้ทางวิทยาศาสตร์ ความคิด และทักษะต่าง ๆ มาประยุกต์ใช้เพื่อสร้างเครื่องมือ วิธีการ หรือสิ่งประดิษฐ์ ที่ช่วยแก้ปัญหาและอำนวยความสะดวกให้มนุษย์ทำงานได้ง่ายขึ้น รวดเร็วขึ้น และมีประสิทธิภาพมากขึ้น

ตัวอย่างเทคโนโลยี

โทรศัพท์มือถือ ใช้ติดต่อสื่อสารและค้นหาข้อมูล

ปัญญาประดิษฐ์ (AI) ช่วยวิเคราะห์ข้อมูลและตอบคำถาม

หุ่นยนต์ ช่วยทำงานในโรงงานและงานที่มีความเสี่ยง

เครื่องซักผ้า ช่วยลดเวลาและแรงงานในการซักผ้า

อินเทอร์เน็ต ช่วยให้สามารถสื่อสารและเข้าถึงข้อมูลทั่วโลก

2. นวัตกรรม (Innovation) และ Innovation Framework
ความหมายของนวัตกรรม: นวัตกรรม คือ การสร้างสรรค์สิ่งใหม่ ๆ หรือปรับปรุงสิ่งที่มีอยู่เดิมให้ดีขึ้น จนเกิดคุณค่าและสามารถนำไปใช้ประโยชน์ได้จริง ไม่ว่าจะเป็นผลิตภัณฑ์ บริการ กระบวนการ หรือรูปแบบธุรกิจ

ตัวอย่างนวัตกรรม

รถยนต์ไฟฟ้า พัฒนาระบบการขับเคลื่อนโดยใช้พลังงานไฟฟ้า

Mobile Banking ทำธุรกรรมทางการเงินผ่านโทรศัพท์มือถือ

การเรียนออนไลน์ เรียนผ่านระบบอินเทอร์เน็ตได้ทุกที่

บรรจุภัณฑ์ย่อยสลายได้ ช่วยลดปัญหาขยะพลาสติก

Innovation Framework คืออะไร?

หมายถึง กรอบแนวคิดหรือกระบวนการที่ใช้ในการสร้างและพัฒนานวัตกรรมอย่างเป็นระบบ ตั้งแต่การค้นหาปัญหา การคิดค้นแนวทางแก้ไข การทดลอง ไปจนถึงการนำไปใช้จริง

ตัวอย่างกระบวนการ Innovation Framework 5 ขั้นตอน

Identify Problem – ค้นหาและระบุปัญหาที่ต้องการแก้ไข

Ideation – ระดมความคิดเพื่อหาแนวทางแก้ไข

Develop – พัฒนาแนวคิดให้เป็นต้นแบบ

Test – ทดลองและประเมินผล

Implement – นำไปใช้งานจริงและปรับปรุงให้ดีขึ้น

ตัวอย่าง: โรงเรียนพบว่านักเรียนเสียเวลาต่อแถวซื้ออาหารกลางวัน จึงคิดค้นระบบสั่งอาหารผ่านแอปพลิเคชัน เพื่อให้นักเรียนสั่งอาหารล่วงหน้าและมารับอาหารได้สะดวกขึ้น

3. Design Thinking (กระบวนการคิดเชิงออกแบบ)
ความหมาย: Design Thinking คือ กระบวนการคิดแก้ไขปัญหาโดยให้ความสำคัญกับผู้ใช้งานเป็นหลัก เพื่อทำความเข้าใจความต้องการ ค้นหาปัญหา และสร้างแนวทางแก้ไขที่ตอบโจทย์ผู้ใช้งานจริง โดยเน้นการคิดสร้างสรรค์และการทดลองปรับปรุง

Design Thinking มี 5 ขั้นตอน

1. Empathize (เข้าใจผู้ใช้) – ศึกษาความต้องการและปัญหาของผู้ใช้งาน เช่น สอบถามนักเรียนว่าทำไมจึงไม่ชอบการต่อแถวซื้ออาหาร

2. Define (กำหนดปัญหา) – วิเคราะห์และระบุปัญหาที่แท้จริง เช่น นักเรียนมีเวลาพักกลางวันน้อย แต่ต้องรอซื้ออาหารนาน

3. Ideate (ระดมความคิด) – คิดหาแนวทางแก้ปัญหาหลายรูปแบบ เช่น ระบบจองอาหารล่วงหน้า หรือเพิ่มช่องจำหน่ายอาหาร

4. Prototype (สร้างต้นแบบ) – สร้างตัวอย่างระบบสั่งอาหารผ่านแอปพลิเคชัน เพื่อทดลองใช้งาน

5. Test (ทดสอบ) – ให้นักเรียนทดลองใช้ระบบ แล้วนำความคิดเห็นมาปรับปรุงให้ดียิ่งขึ้น
